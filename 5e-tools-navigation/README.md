# 5e.tools Navigation

Keyboard navigation improvements for [**5e.tools**](<https://5e.tools>).

## Features

- Navigate the list using **Arrow Up (↑)** and **Arrow Down (↓)**.
- Jump approximately 30 entries using **Page Up** and **Page Down**.
- Automatically scrolls the selected entry into view.
- Automatically activates the selected entry.
- Works on all pages of **5e.tools** that use the standard left-hand navigation list(s).

## Installation

1. Install a compatible userscript manager.
2. Install `5e-tools-navigation.user.js`.

For general installation instructions and browser-specific notes (including Chromium's **Allow User Scripts** setting), see the [repository README](<https://github.com/malijaffri/userscripts#README>).

## Compatibility

Tested with:

- Violentmonkey on Firefox
- Tampermonkey on Chromium
